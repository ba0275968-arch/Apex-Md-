## 📲 Setup & Deployment

බොට්ව වැඩ කරවන්න පල්ලෙහා තියෙන ක්‍රම දෙකෙන් කැමති එකක් පාවිච්චි කරලා `SESSION_ID` එක ලබාගන්න.

### 1️⃣ Method 1: Get Session ID via Pair Code (No second phone needed)
